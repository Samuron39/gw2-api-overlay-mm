# GW2 Overlay 0.4.15

ArcDPS kan installeres rett fra Live-fanen.

- **Ny knapp «Installer ArcDPS og broen»** i kortet ArcDPS-bro på Live-fanen. Den vises bare når ArcDPS mangler eller er gammel, og er da hovedknappen. «Installer broen» tones ned, så det er tydelig hva som trengs.
- **Samme installasjon som i Kom i gang:** ArcDPS lastes ned fra utviklerens side og sjekkes mot sjekksummen, broen installeres i samme omgang, fremdriftslinja vises i kortet, og appen venter ti sekunder for å se at antivirus ikke fjerner fila.
- **Når spillet kjører** er knappen grå, og kortet forklarer at spillet må lukkes først.
- **Når alt er i orden** vises ikke knappen.

Bakgrunn: Windows Defender fjernet ArcDPS på nytt 19. september. Live-fanen hadde bare en knapp for broen, så det så ut som broen var feilen, mens det var ArcDPS som manglet.

285 automatiske tester består. Broens kode og protokoll er uendret.
